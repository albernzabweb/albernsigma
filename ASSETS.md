# Asset provenance

All six SVG product illustrations in `public/products` and `app/icon.svg` are original procedural vector artwork created for this project. The camera in `components/camera-scene.tsx` is an original procedural Three.js illustration, clearly labeled as such. No third-party GLB/GLTF or Spline scene is bundled. Brand/product names identify illustrative catalogue examples; the artwork is not manufacturer product photography. Sample testimonials and statistics are marked illustrative.

No external 21st.dev component source was copied. UI primitives use installed open-source Radix/CVA dependencies; package license files remain in their distributions after `npm ci`.
